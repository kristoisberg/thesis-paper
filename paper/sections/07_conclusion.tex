\section{Conclusion}\label{sec:conclusion}

For RQ1, one selected-detector run achieved micro precision \num{0.858}, recall \num{0.880}, and F1-score \num{0.869} against the \num{523} original single-annotator reference spans in the held-out partition. Per-class F1 ranged from \num{0.481} to \num{0.974}. This range requires class-specific interpretation of the pooled score.

For RQ2, the detector produced \num{15931} flags in \num{601} of the \num{602} repositories. Implicit Columns and ID Required accounted for \qty{68.3}{\percent} of all flags, while the highest-count \qty{10}{\percent} of flagged repositories contained \qty{59.1}{\percent} of the output. For RQ3, the two leading Implicit Columns source-fragment patterns comprised \qty{71.7}{\percent} of that class's flags, and fragments matching \texttt{like(} comprised \qty{46.8}{\percent} of Poor Man's Search Engine flags.

This occurrence-level evaluation shows how closely one selected-detector run agrees with the original reference for the class-labelled span outputs later counted as corpus flags. The corpus findings support class-specific statements about detector flags; true antipattern prevalence and API-associated risk remain unmeasured. Independent reference annotation, repeated detector runs, corpus transfer evaluation, and exposure-normalised measures are needed for stronger claims.
