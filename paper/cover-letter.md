# Cover Letter Draft

Dear Editors of *Empirical Software Engineering*,

Please consider our manuscript, “Validating LLM-Based Localisation for Mining SQL Antipatterns in jOOQ Repositories,” as a Research Article.

The study evaluates SQL-antipattern detection as a multi-label, multi-occurrence line-span localisation task on a project-disjoint held-out dataset and then uses the validated detector as a fallible measurement instrument across 602 open-source jOOQ projects. Its contribution is the linked protocol: occurrence-level validation, class-specific uncertainty, and bounded repository findings about detected prevalence, exploratory co-detection, and API associations. The paper is relevant to software maintenance, quality assurance, mining software repositories, and applications of artificial intelligence to software engineering.

The manuscript does not claim that LLMs supersede deterministic static analysis. It identifies stable API patterns suited to rules and treats context-dependent classes and corpus outputs according to their measured limitations. It also states that the study used one annotator, single LLM runs, no separate population-output audit, and no project-size adjustment for co-detection analyses.

## Prior dissemination

This article is based on Kristo Isberg's publicly available master's thesis, *Detecting SQL Antipatterns in jOOQ Database Access Code Using Large Language Models*. The repository corpus, annotated dataset, detector implementation, model and prompt experiments, and large-scale measurements originate in that thesis and are not presented as newly collected or as an independent replication. The journal manuscript selects and synthesises that evidence around an occurrence-localised measurement protocol, updates its positioning against related empirical software-engineering research, and explicitly propagates class-specific instrument limitations into the repository claims. The thesis has not been presented as a prior journal publication.

The manuscript is not under consideration elsewhere. All authors will approve the final manuscript and disclosures before submission.
