\begin{abstract}
Traditional static analysis tools struggle to detect SQL antipatterns in dynamically generated queries built with domain-specific languages like the Java library jOOQ. To address this limitation, this thesis develops an LLM-powered static analysis tool capable of identifying SQL antipatterns directly from jOOQ database access code.

The methodology involved creating a single-annotator reference dataset of \num{1562} antipattern occurrences from 61 open-source projects. Against the original held-out reference spans, one selected Claude Opus 4.5 run using a Zero-Shot prompt achieved micro precision of \num{0.858}, recall of \num{0.880}, and F1-score of \num{0.869}; complex reasoning prompts increased costs without consistent metric improvements.

Deploying the finalised tool across 602 projects produced \num{15931} flags across seven classes. Implicit Columns and ID Required had at least one flag in \qty{89}{\percent} and \qty{87}{\percent} of the projects. Among Implicit Columns flags, \qty{71.7}{\percent} matched the two largest post hoc API manifestation categories; among Poor Man's Search Engine flags, \qty{46.8}{\percent} matched \texttt{Field.like}. The occurrence-level agreement bounds how these unnormalised detector outputs can be interpreted.

The finalised tool is available in the following GitHub repository: \href{https://github.com/kristoisberg/jooq-antipattern-detector}{https://github.com/\\kristoisberg/jooq-antipattern-detector}. All other artefacts produced as parts of the thesis are available in the following GitHub repository: \href{https://github.com/kristoisberg/masters-thesis}{https://github.com/kristoisberg/masters-thesis}.

\end{abstract}
